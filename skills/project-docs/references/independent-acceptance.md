# 独立上下文验收

用于本 skill 承接的文档任务，默认全部独立验收。执行者负责发起、处理发现并交付；验收者负责只读检查，不再为本次验收递归创建验收者。任务范围决定验收工作量，局部修改也要独立检查对应内容、契约和修改边界；只有入口列出的实际限制才降级自验收。

## 实际创建隔离的验收上下文

自检完成后，调用环境提供的子代理工具，明确使用不继承执行历史的选项。工具提供 `fork_turns="none"` 等隔离选项时应实际设置；只写“独立审查”、在原对话换角色或复制全部执行历史都不算隔离。无需用户另开窗口，也不为此额外创建项目或工作树。

应有当前执行者创建另一个验收上下文的实际工具记录；执行者本身由外层调度器新建，不能替代这次委派。首次委派明确标注接收者的验收身份、只读职责和不递归触发本机制的边界，避免其再次作为执行者启动验收链。

验收仍受原任务的权限、范围和资源限制约束。工具不可用、不能关闭历史继承或调用失败时，完成可进行的自验收，记录未完成的独立环节；不编造验收者或通过结论，不反复创建相同任务等待偶然通过。

## 首次交接只给任务与材料

向验收者提供足以独立工作的材料：

- 原始请求、仅审查或可修改的任务类型、范围与排除项、完成条件。
- 用户给定的读者背景、版本和语境，以及仓库指令、skill 与适用规范的入口；推定的背景应标明，允许验收者核对。
- 待验收的最终文档或原始审查对象，以及必要的源码、契约、配置、模板和引用路径。知识隔离不等于省略事实来源。

首次不提供执行者的疑点清单、修复清单、发现数量、通过结论或预期答案。要求验收者先独立返回具体发现、保留依据、实际覆盖和未确认项，再做报告对照。已有执行报告或旧审查笔记可以在首次任务中列为暂不读取的材料，不能先发送全文后仅要求忽略。

共享目录时，执行者在验收期间暂停修改被验收材料。绑定当前版本或文件指纹即可，无需强制提交。外部并发变化使输入改变时，重新核对受影响部分，不能沿用旧材料的通过结论。

## 独立检查与报告对照

验收者从原始请求生成适用检查项，按[文档类型与改写判断](document-types.md)核对事实、结构、表达、操作路径和必要保留项。检查范围包含未修改内容，不以差异、作者的检查清单或发现数量代替整体范围。通过结论应能回到具体读者任务与材料位置；独立上下文本身不证明质量。

收到首轮独立结论后，再把执行报告与改动范围交给同一验收者对照；修改任务同时提供原始版本或 diff，检查遗漏、误报及知识丢失。仅审查任务对照的是问题报告的依据与覆盖，验收者不能顺手改正文。原文、规范或事实来源与执行报告冲突时回查来源，不因作者已核对而直接采信。

报告对照还要核对判断范围与证据是否匹配。合并的每处位置应能还原具体问题关系，不能用某一处成立的分析替其余位置补齐；必要操作与背景混合时，检查保留结论是否只适用于其中一部分。新写或替换的说明也要重新判断当前位置的必要性，不能因原背景已删除，或同一信息在另一篇文档中应保留，就直接认可新的放置方式。事实正确、已列发现成立或没有操作阻断，都不能代替局部表达判断及原范围中未报告、未修改内容的检查。

发现只有位置清单、重复却未说明对应关系、笼统保留整节或尚未区分混合内容等不足时，指出具体位置与缺少的判断，返回执行者补查、补写或收窄结论，再交回同一验收者复核。问题已准确报告但原文尚未修改，不影响只读审查报告通过；未完成表达判断或覆盖不足则不能仅以事实核对通过交付。依据与覆盖充分时不要求拆成固定数量的条目，也不强制逐句留表。

只读验收不运行有额外副作用的产品流程，也不扩大文件范围。需要更多上下文时在原范围内读取必要材料；无法确认的事项明确保留，不能凭执行者的肯定结论计为通过。

## 处理发现与结束

执行者核实验收发现。修改任务在原授权内修复，审查任务补充或纠正报告；有分歧时按事实来源、读者任务和适用规范说明接受或不接受的理由。验收者不直接写入与执行者共享的目标文件。

未通过时，由执行者在原授权内修订交付物，把变更与影响交回同一验收者复核；若仍未通过则继续修订、复验，直到约定范围通过。确认相关问题及必要保留项，仍对照原始范围中的未完成部分，不能只验最初几个发现。局部修复不要求重新检查无关区域；变更改变了前提、公共事实或跨文档关系时，扩大到实际受影响的阅读路径。

验收对象通过后才交付完成结论；仅审查任务以报告正确、覆盖充分为通过对象，原文仍可有报告中列出的问题。证据不足、权限受限、争议未解或检查未完成时，保留未通过或待确认，说明具体剩余事项；不能为结束任务强行通过，也不在没有新证据时更换代理等待偶然通过。不得按固定轮数、调用次数或任务看似简单提前结束尚有可处理问题的修订。

交付简要说明实际采用独立验收还是自验收、检查范围、处理结果及剩余限制。仅提出委派计划、未实际调用工具或未收到结果，不能称为已独立验收。
