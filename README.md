# Second Nature

Personal skills for AI agents.

个人维护的 AI Agent 技能库。将自己的工作方法、领域判断和实践经验，沉淀为 AI 可以按任务使用的技能。

Second Nature 取自英语习语，指一种做法已经熟练到不必刻意思考。这个仓库希望保存那些值得反复使用的方法，让好的工作方式可以在不同任务中复用。

## 为什么积累这些技能

在反复使用 AI 的过程中，总会遇到一些需要多次交代的事情：如何判断证据是否充分，如何组织一次排查，交付前需要确认哪些结果。这些经验往往散落在对话和笔记中，下一次遇到类似任务时又需要重新整理。

Second Nature 将这些经验写成有适用范围、执行方法和结果判据的技能，用 Git 保存修改，并通过真实任务的反馈持续改进。

## 什么适合成为技能

- **可重复的方法**：一类任务中稳定有效的工作步骤，例如排查问题、审阅变更或整理实验结果。
- **领域中的判断依据**：任务需要的术语、约束、数据口径和容易遗漏的条件。
- **产物的质量标准**：怎样判断报告、代码或分析结论已经满足要求。

例如，一个实验报告审查技能可以规定如何核对对照设置、指标口径和结论证据。值得积累的是这套判断方法，以及验证它是否有效的真实请求。

按任务复用的方法放在技能中；跨任务的个人偏好和只适用于某个项目的约定，分别留在个人设置和项目指令中。更详细的边界见 [设计说明](docs/design.md#指令放在哪里)。

## 一个技能如何组织

技能遵循 [Agent Skills](https://agentskills.io/specification) 格式，以 `SKILL.md` 为入口。下面是组织形式，辅助资源按需添加：

```text
skills/<name>/
|-- SKILL.md       名称、适用条件与任务指导
|-- references/    按需读取的领域资料和详细说明
|-- scripts/       可执行的辅助程序
`-- assets/        生成产物时使用的模板与素材
```

`SKILL.md` 的 frontmatter 描述技能的名称和用途，正文提供完成任务需要的指导。较长的资料和确定性操作分别交给引用文件与脚本，让入口保持聚焦。

支持该格式的客户端可以加载这些指令和资源。不同工具的发现路径、调用方式和权限配置有所不同，具体使用方式见 [使用指南](docs/usage.md)。技能在执行任务时提供上下文和方法，不修改模型权重。

## 维护原则

- **范围明确**：描述清楚技能处理什么任务、何时适用，避免宽泛触发。
- **独立可用**：一个技能包含自身需要的指导和资源，工具依赖明确声明。
- **按需展开**：入口保留关键判断，详细资料在需要时读取。
- **以结果迭代**：分别检查格式、技能选择和任务产物，依据观察到的问题改进内容。

## 从这里开始

### 使用技能

1. 从 [skills/](skills/) 浏览技能，阅读其适用范围和依赖。
2. 按 [使用指南](docs/usage.md) 安装到所用客户端。
3. 用实际请求确认技能能被发现、正确使用，并检查最终结果。

### 沉淀自己的方法

1. 选择一类反复出现、需要经常纠正 AI 的任务。
2. 按 [编写指南](docs/authoring.md) 创建技能，写清关键判断与执行方法。
3. 按 [评测指南](evals/README.md) 准备真实请求，检查触发范围与任务效果，再根据反馈迭代。
