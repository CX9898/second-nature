# SampleKit

SampleKit 统计 JSON 数组的记录数和批次数。

本次根据对话补齐了工具，当前默认使用 CUDA，后续模型接着检查即可。整理人在 `/home/demo-user/work/samplekit` 完成了运行。

在仓库根目录执行：

```bash
python3 tool.py --input-file examples/input.json --output results
```

配置详情见 [配置参考](docs/config.md)，运行过程见 [快速开始](docs/quickstart.md)。
实现与推导见 [批次计数](docs/batching.md)。

维护者公开联系地址为 maintainers@example.org，许可证见 [LICENSE](LICENSE)。
