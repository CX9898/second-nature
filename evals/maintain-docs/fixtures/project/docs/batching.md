# 批次计数推导

本节对应 `tool.py` 中的 `Runner.summarize`。

## 符号与条件

`N` 表示 JSON 数组的记录数，满足 `N >= 0`；`B` 是正整数批次大小。
`K` 表示覆盖全部记录所需的批次数。

## 整数推导

由整除关系，存在 `q`、`r` 使 `N = qB + r`，且 `0 <= r < B`。
当 `r = 0` 时，`K = q`；当 `r > 0` 时，`K = q + 1`。
因此 `K = ceil(N / B)`，等价的非负整数表达式为：

```python
batches = (N + B - 1) // B
```

空输入 `N = 0` 时结果为零。`B <= 0` 时构造函数拒绝配置，避免除零或错误计数。

## 覆盖关系

按顺序划分时，第 `j` 批覆盖区间 `[jB, min((j+1)B, N))`。
这些区间互不重叠，长度之和为 `N`，最后一批最多含 `B` 条记录。

## 实现和资源边界

计数运算使用 Python 整数，计算本身不遍历数组，也不复制各批记录。
当前 CLI 使用 `json.loads` 一次加载输入数组，因此整体输入存储仍随 `N` 增长。
该工具并未实现流式输入或实际批次调度。

## 可复核样例

`N=3, B=2` 时 `K=2`；`N=4, B=2` 时 `K=2`；`N=0, B=2` 时 `K=0`。
