# PackTrail

PackTrail 将本地目录打包为 `.ptb` 归档，提供创建、校验和恢复三个入口。

用户操作见 [备份指南](docs/backup.md)，配置示例见 [backup.json](examples/backup.json)。
[接口契约](contract.json) 记录当前版本的参数、路径解析与归档行为。

## 归档的生命周期

创建归档时，PackTrail 扫描源目录、应用过滤条件，并按配置压缩和加密文件内容。
写入结束后封口块索引。校验入口检查归档自身是否完整；恢复入口读取索引，解密并解压文件。

每次创建都产生完整归档，不使用增量链。已有归档不会因为源目录或配置变化而自动更新。

## 运行环境

以下接口契约和指南以命令已安装、在项目工作目录运行的环境为前提。
本材料不提供安装流程，也不要求运行备份、校验或恢复来完成文档整理。
