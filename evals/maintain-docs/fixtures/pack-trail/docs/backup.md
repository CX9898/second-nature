# 创建并校验目录备份

本页说明如何为本地目录创建完整归档并确认归档可读取。命令以已安装 PackTrail、
在项目工作目录运行的环境为前提。配置格式和行为以 [接口契约](../contract.json) 为准。

## 准备输入和输出

确认源目录 `project` 存在，并在源目录之外准备输出目录 `backups`。
输出目录需要事先存在，不能将归档文件放入源目录，否则创建会被拒绝。

本示例使用 [backup.json](../examples/backup.json)。配置中的路径相对于运行命令的
工作目录解析，不是相对于配置文件所在目录。因此从项目根目录运行示例时，
源目录是 `project`，归档为 `backups/project.ptb`，密码文件是根目录中的 `backup.key`。

## 选择配置

`exclude_hidden` 默认为 `true`，跳过名称以点号开头的文件和目录子树。
需要备份这些内容时设为 `false`。`compression` 可选 `none` 或 `gzip`；
省略时为 `none`，示例显式使用 `gzip`，恢复时 PackTrail 自动解压。

创建时使用随机 UUID 作为初始快照标识，本示例没有设置标识分配方式。

`password_file` 指向已有的密码文件。设置该字段会加密归档，省略或设为 `null`
则不加密。校验和恢复加密归档时需要创建时的相同密码，文件路径可以不同。
请妥善另存密码；PackTrail 无法找回丢失的密码。

`overwrite` 默认为 `false`，同名归档存在时终止并保留原文件。
需要替换时可设为 `true`，但替换不保留旧版本且无法撤销；也可以选择新的输出路径。

## 修改配置和源目录

下次创建会重新读取源目录并应用新的过滤条件。恢复器按块索引定位压缩帧，
块索引在归档封口后只读。修改源目录或配置不会更新已有归档，需要重新创建归档。

## 创建归档

准备好配置和密码文件后，在项目根目录执行：

```bash
packtrail create --config examples/backup.json
```

归档写入配置指定的 `backups/project.ptb`。如果保留 `overwrite=false`，
再次运行前应选择新的输出路径，或确认原归档已不再需要后再决定是否覆盖。

加密归档校验时使用创建时的相同密码。校验通过会以状态码 0 退出并输出
`Archive verified`；校验不会比较当前源目录，也不证明过滤条件包含了所有预期文件。

## 校验归档

加密归档校验时使用创建时的相同密码：

```bash
packtrail verify backups/project.ptb --password-file backup.key
```

未加密的归档不需要 `--password-file`。校验通过会以状态码 0 退出并输出
`Archive verified`；失败时以非零状态码退出，不能将归档视为已通过校验。

校验会读取全部文件记录，解码压缩帧，并核对明文 SHA-256 与解压后的长度。
它证明归档自身可读取且内容校验通过，不比较当前源目录，也不证明过滤条件
包含了所有预期文件。请另外检查 `exclude_hidden` 是否符合备份范围。
