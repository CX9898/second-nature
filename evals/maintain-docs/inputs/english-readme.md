# SampleKit

SampleKit reports row and batch counts for a JSON array using the CPU backend.
It requires Python 3.10 or later and uses the standard library.

Run from the repository root:

```bash
python3 tool.py --input examples/input.json
```

The command writes `results/report.json` and prints its location on success.
Configuration and instance defaults are described in the configuration reference.
