# 分片交接记录

- 运行条件：Python 标准库；示例的执行目录是项目根目录。
- `read_parts()`：输入为 CSV 零件记录；输出为按包裹编号排序的分组映射；每组保留
  零件名称和重量。
- `read_checks()`：输入为检查 CSV；输出为按文件行顺序排列的布尔值。
- `check_parcels()`：输入为分组映射，可选检查值按映射顺序每包裹一个；返回包裹数，
  提供检查值时另返回接受数。
- `save_checkpoint()`：输入为分组对象；输出为 SQLite 检查点，包含包裹编号、
  零件名称和重量，保存在 `parts` 表。
- `restore_checkpoint()`：消费者输入为该 SQLite 检查点的 `parts` 表；输出为完整分组；
  不需要原始 CSV。
- `write_totals()`：输入为分组对象；输出为 SQLite 汇总的 `counts` 表，仅含编号和
  零件数，不含零件名称或重量。
- `read_totals()`：消费者输入为汇总的 `counts` 表；输出为按包裹编号排序的
  编号到零件数映射，供展示使用。
- 写入行为：两个写入函数都会替换同名文件中自己的表内容，并移除另一类产物的数据表。

这份记录描述接口关系，不包含成稿验收结论。
