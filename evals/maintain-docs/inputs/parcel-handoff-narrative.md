# 分片交接记录

ParcelDesk 使用 Python 标准库，示例从项目根目录执行。`read_parts()` 将 CSV 零件
记录按包裹编号分组，返回按编号排序的映射，每组保留零件名称和重量。
`read_checks()` 按 CSV 的行顺序返回布尔值。`check_parcels()` 接收分组映射，
检查值可省略；提供时须按映射顺序为每个包裹提供一个值，返回包裹数和接受数，
不提供时只返回包裹数。

保存模块的 `save_checkpoint()` 接收分组对象，将包裹编号、零件名称和重量写入
SQLite 检查点的 `parts` 表。`restore_checkpoint()` 读取该表恢复完整分组，不需要
原始 CSV。`write_totals()` 也接收分组对象，将编号和零件数写入 SQLite 汇总的
`counts` 表，不保存零件名称或重量。`read_totals()` 读取汇总，按包裹编号排序返回
编号到零件数的映射，供展示使用。两个写入函数都会替换同名文件中自己的表内容，
并移除另一类产物的数据表。

这份记录描述接口关系，不包含成稿验收结论。
