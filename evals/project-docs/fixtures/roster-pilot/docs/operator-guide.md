# 生成并发布班表

本页用于修改日期和单班上限、生成预览并发布。日期与班次时间均按 UTC 解释。
使用[示例配置](../examples/shift.json)，命令从项目根目录运行；行为以[契约](../contract.json)为准。

## 选择配置

`day` 选择 UTC 日期，`max_shift_hours` 是 1 到 24 的整数小时数，省略时为 8。
预览命令以有界搜索建立候选集合；SDK 也可选择完整搜索，夜间优化器可据此生成新预览。

## 更新配置

保存配置后，下一次生成预览才会采用新值。候选的同分排序使用员工标识和班次开始时间。
已有预览及活动班表不会因此改变，只有发布新预览才替换活动班表。

## 生成预览

```bash
rosterpilot preview --config examples/shift.json
```

命令输出预览标识，后续命令使用这次标识替换 `PREVIEW_ID`。
校验返回 0 并输出 `Ready` 表示必需班次、人员可用性和硬约束检查通过，
不证明所有偏好均满足，也不证明结果是全局最优。

## 校验预览

```bash
rosterpilot check PREVIEW_ID
```

返回 0 并输出 `Ready` 表示必需班次、人员可用性和配置硬约束检查通过；
其他结果不能作为已通过。校验不保证满足每个人的偏好，也不证明全局最优。

## 发布选定预览

先校验要发布的同一个预览标识；换用其他预览时需要重新校验。
此操作替换当前活动班表，工具不提供回滚，也不保留旧活动版本历史。

```bash
rosterpilot publish PREVIEW_ID --replace-active
```

发布读取已经选定的不可变预览，不重新求解。服务对象构造时仍以有界搜索初始化，
完整搜索可由 SDK 或夜间优化器选择。
